# Verdeva | Conscious Living

A sustainable lifestyle e-commerce website built around thoughtful choices, timeless design, and more conscious everyday living.

Verdeva is a sustainable lifestyle e-commerce website concept that encourages people to make more thoughtful choices in their everyday lives.

The project combines a clean, minimalist aesthetic with a nature-inspired visual identity. Its purpose is to showcase carefully selected everyday essentials while communicating the values of conscious consumption, quality, and simplicity.

The design uses a natural colour palette, elegant typography, and a responsive layout to create a calm and intuitive shopping experience.

Brand Identity

Brand name: Verdeva

Tagline: Live consciously. Choose better.

Industry: Sustainable lifestyle and e-commerce

Visual direction: Minimalist, natural, modern and editorial

Primary colours: Forest green, sage, warm cream and beige

Typography: Playfair Display and DM Sans

Website Features

Homepage: Brand introduction, featured collections, bestsellers and editorial content.

Shop: Product catalogue with a focus on sustainable everyday essentials.

Our Impact: Brand philosophy, guiding principles and conscious living values.

Journal: Editorial content related to sustainability and mindful living.

Shopping Bag: Shopping bag interface for selected products.

Responsive Design: Layouts adapted for desktop, tablet and mobile devices.

Technologies

The project is built using:

HTML5 — Website structure and semantic markup.

CSS3 — Styling, responsive layouts, animations and visual design.

TypeScript — Typed application logic.

JavaScript — Compiled output generated from TypeScript.

Google Fonts — Playfair Display and DM Sans.

GitHub Pages — Website hosting and deployment.

GitHub Actions — Automated TypeScript compilation and deployment workflow.


Build and Development

The project uses TypeScript to manage application logic.

Requirements

Node.js

npm

Install dependencies

npm install

Compile TypeScript

npm run build

Watch for changes

npm run watch

The compiled JavaScript output is generated in the js/ directory.

Deployment

Verdeva is hosted using GitHub Pages.

A GitHub Actions workflow automatically:

Checks out the repository.

Sets up Node.js.

Installs project dependencies.

Compiles TypeScript.

Uploads the website as a GitHub Pages artifact.

Deploys the updated website.

The workflow runs when changes are pushed to the main branch.

Design Philosophy

Verdeva is guided by four core principles:

Thoughtfully sourced — Looking for considered materials and products with a clear purpose.

Made to last — Valuing quality, practical design and lasting usefulness.

Less unnecessary waste — Appreciating reusable alternatives and more mindful habits.

Conscious living — Believing in small, realistic changes that become lasting habits.





The website is an ongoing project. New features, improvements and refinements may be introduced as development continues.
